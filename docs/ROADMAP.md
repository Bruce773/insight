# Roadmap

- Calibrate the provisional facet-to-work-style mapping against appropriate evidence.
- Evaluate demand weighting using BLS Employment Projections and, if licensed, Lightcast data.
- Collect user “fits / doesn't fit” feedback and evaluate whether it can improve matching weights.
- Check instrument and score reliability.
- Explore optional observer ratings with informed consent.
- Design a longitudinal validation study of exploration outcomes.
